## 重现本次验证

在PowerShell中将本目录记为$probeRoot。依赖路径见host.json、qt-package.json和下列命令。SDK目录必须存在。首次构建日志已保留；后续不要覆写本次证据。

```powershell
$probeRoot = '本记录所在的实际目录'
$run = Join-Path $probeRoot ('reruns/' + (Get-Date -Format 'yyyyMMdd-HHmmss') + '-' + [guid]::NewGuid().ToString('N').Substring(0,8))
New-Item -ItemType Directory -Path $run -ErrorAction Stop
cmake -S $probeRoot -B (Join-Path $run 'build') -G 'Visual Studio 17 2022' -A x64 '-DCMAKE_PREFIX_PATH=E:/Anaconda3/Library'
if ($LASTEXITCODE -ne 0) { throw '配置失败，不运行旧程序' }
cmake --build (Join-Path $run 'build') --config Release
if ($LASTEXITCODE -ne 0) { throw '构建失败，不运行旧程序' }
$env:PATH = 'E:\Anaconda3\Library\bin;' + $env:PATH
$env:QT_QPA_PLATFORM_PLUGIN_PATH = 'E:\Anaconda3\Library\plugins\platforms'
$env:QT_QPA_PLATFORM = 'windows'
$p = Start-Process -FilePath (Join-Path $run 'build/Release/a01_probe.exe') -WorkingDirectory $run -WindowStyle Hidden -RedirectStandardOutput (Join-Path $run 'stdout.log') -RedirectStandardError (Join-Path $run 'stderr.log') -PassThru
if (-not $p.WaitForExit(20000)) { Stop-Process -Id $p.Id; throw '探针超时，保留运行目录' }
$p.WaitForExit()
if ($p.ExitCode -ne 0) { throw '探针失败，检查日志' }
& 'E:\APP\Wireshark\tshark.exe' -r (Join-Path $run 'loopback.pcap') -T fields -E header=y -E separator=, -e frame.number -e frame.len -e ip.src -e ip.dst -e ip.version -e udp.srcport -e udp.dstport -e udp.length -e udp.payload | Set-Content -LiteralPath (Join-Path $run 'tshark-fields.csv') -Encoding utf8
Copy-Item -LiteralPath (Join-Path $probeRoot 'verify_bytes.py') -Destination $run
python (Join-Path $run 'verify_bytes.py')
```

以上是本次已执行步骤的复现说明，不是A07整套实验自动化；重跑示例本身未再次执行。脚本只适用于本探针固定PCAP布局，不是通用协议解析器。
